Hasp

This extension is a window onto a vault running on this machine. It holds no secrets of its own.

Vault address

Only http on 127.0.0.1 or localhost is accepted. A remote address would send your session cookie to a server this extension does not control, so it is refused rather than warned about.

What this extension can and cannot do

  • It reads the vault's item list over loopback and copies a value or a code when you ask.
  • It does not read page content. There is no content script.
  • It does not type into fields. Filling forms needs a threat model that does not exist yet.
  • It stores one setting, the address above. The session lives in a cookie it cannot read.
