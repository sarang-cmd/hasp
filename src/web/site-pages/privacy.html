Privacy

Last updated 4 November 2026

DraftThis policy describes the software in this repository. It has not been reviewed by a lawyer, and no company entity operates a hosted service behind it.

What Hasp processes

Hasp stores the items you add: names, services, hosts, environments, notes, secret values, one-time code secrets and backup code sets. It also stores the parameters used to derive your key, and the wrapped vault key.

It does not collect analytics, telemetry, usage events, device identifiers or crash reports. There is no account and no email address.

Where the data goes

Nowhere. The vault is a single encrypted file at .vault/vault.json in the directory you ran it from, unless you set HASP_EPHEMERAL=1, in which case nothing is written to disk at all.

The interface is served by the same process that holds the key. That process makes no outbound request at runtime. Company marks, fonts and icons are served from the project folder rather than a CDN.

What the server can see

DraftThis is the important limitation, and it is a property of the current architecture rather than a policy choice. The server derives your key and seals items, which means plaintext passes through the Node process and over the loopback interface. Anyone who can read that process's memory can read the vault key. A future version is intended to move this work into the browser, which would change this paragraph.

Third parties

None are contacted by the software. DraftIf a hosted version is ever operated, this section will need the hosting provider, the region, the sub-processors and the lawful basis for each. None of those decisions exists yet.

Your rights

DraftA hosted service would owe you access, correction, deletion and portability. Because there is no service and no account, the practical answer is that the file is yours: delete it and the data is gone. Export is available from the Settings screen.

Retention

DraftNo retention period is defined because there is no service retaining anything. The file persists until you delete it.
