About

A small tool for one job.

Hasp began as a way to stop keeping API keys in a note-taking app. It stayed small on purpose.

Why it exists

API keys accumulate. Each one is generated in a console, pasted into a note, and forgotten until it appears in a log. The tool that should hold them is a password manager, but those are built for passwords: they do not track which environment a key belongs to, when it rotates, or which one a test suite should use.

Hasp is a vault that understands keys as items with metadata: a service, a host, an environment, an owner and a rotation habit.

What it is built from

One Node process and a folder. The client has no runtime dependencies and no CDN. Icons are Heroicons solid, vendored with their licence. The 586 company marks come from Simple Icons and SVG Logos, vendored so the app works offline. The three typefaces are served from the project.

The design system is four token combinations for two directions and two modes, plus three accent styles. The contrast floor is a test, not a promise, and it parses the stylesheet to enforce it.

What is deliberately missing

Sync, accounts, sharing, a browser extension, a desktop app and a mobile app. Each is a real product decision with a real cost, and each is listed on the product page rather than implied by a screenshot.

The shorter version: Hasp does one job on one machine, and it says so.
