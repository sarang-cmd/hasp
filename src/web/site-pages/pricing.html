Pricing

Free while it is in development.

There is no paid tier and no billing system. A price list would be a claim about a product that does not have one yet, so this page does not invent one.

What that means

Cost today
Nothing. Run it from source.
Accounts
None exist, so there is nothing to bill against.
Hosting
You host it, if you choose to. Hasp makes no hosted service available.
Future pricing
Undecided. When there is a number it will appear here, in this list.

If you need the key management features today, the demonstration is complete and free. If you need sync, sharing or a hosted service, Hasp does not offer them yet.
