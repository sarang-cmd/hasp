Documentation

Run it in two commands.

Hasp needs Node 22 or newer. There is no database, no environment variable and no network access at runtime.

Start

npm install
npm start

Then open http://localhost:3000. The sample master password is foundry-nightshift-2026 and it is filled in for you.

Import your exports

Open Imports, then drop a file or paste text. Hasp detects the format: Google Keep JSON or HTML, CSV, otpauth URIs, and the JSON exports of Aegis, 2FAS, Raivo, Bitwarden, Google Authenticator and Microsoft Authenticator.

Every candidate carries a confidence score. Anything under 70 percent goes to review before it is stored. A parsed import can be accepted once, and it expires after 30 minutes.

Keys worth knowing

Search
/ or Cmd K focuses the search field.
Escape
Closes the editor, or leaves the walkthrough.
Unlock
The field takes focus on load, so you can type immediately.
